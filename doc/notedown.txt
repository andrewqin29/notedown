*notedown.txt*  A note format for Neovim, built on markdown

notedown renders markdown notes in the buffer, with a note format of its own.
See the README (https://github.com/andrewqin29/notedown) for the format.

==============================================================================
COMMANDS                                                    *notedown-commands*

:help  or  <F1>     In a markdown file, a popup of what to write and the
                    commands; q or <Esc> closes it. `:help {topic}` is
                    still Neovim's own |:help|.                     *:Help*
:toc  or  gO        Table of contents popup: j/k to move, <CR> to jump, q or
                    <Esc> to close.                                 *:Toc*
:read               Toggle reading mode: full width, read-only, everything
                    rendered under the cursor. <Esc> leaves it.     *:Read*
                    (`:read {file}` is still Neovim's own |:read|.)
:raw                Toggle raw reading mode: reading mode with nothing
                    rendered, the note as typed. `:read` and `:raw`
                    switch between the two.                         *:Raw*
:Notedown           Toggle rendering.                               *:Notedown*

==============================================================================
COLORS                                                        *notedown-colors*

notedown's highlight groups are named Notedown*, listed in
lua/notedown/highlights.lua. Most link to the colorscheme's groups as
defaults, so a colorscheme can set them.
